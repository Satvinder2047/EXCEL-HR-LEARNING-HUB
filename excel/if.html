IF Function in Excel

Perform logical tests and return different values based on conditions.

Syntax

=IF(logical_test, value_if_true, value_if_false)

Description

The IF function checks whether a condition is TRUE or FALSE. If the condition is TRUE, Excel returns one value. If FALSE, it returns another value.

Arguments

Argument Description
logical_test The condition to test.
value_if_true Returned when condition is TRUE.
value_if_false Returned when condition is FALSE.

Example 1

=IF(A2>=35,"Pass","Fail")
Result ``` Marks Result 45 Pass 20 Fail ```

Example 2

=IF(B2="Yes","Approved","Pending")

Common Uses

  • Attendance
  • Salary Calculation
  • Bonus Calculation
  • Shift Allocation
  • Payroll
  • HR Reports

Nested IF

=IF(A2>=90,"A", IF(A2>=75,"B", IF(A2>=50,"C","Fail")))
