IF Function in Excel

Perform logical tests and return different values based on conditions.

📚 Excel Functions

🟢 Beginner

Syntax

=IF(logical_test, value_if_true, value_if_false)

Description

The IF function checks whether a condition is TRUE or FALSE. If the condition is TRUE, Excel returns one value. If the condition is FALSE, it returns another value. It is one of the most commonly used logical functions in Excel.

Arguments

Argument Description
logical_test The condition you want to test.
value_if_true Returned when the condition is TRUE.
value_if_false Returned when the condition is FALSE.

Example 1

=IF(A2>=35,"Pass","Fail")
Marks Result
45 Pass
20 Fail

Example 2

=IF(B2="Yes","Approved","Pending")

If cell B2 contains "Yes", Excel returns Approved; otherwise it returns Pending.

Common HR Uses

  • Attendance Status
  • Salary Calculation
  • Bonus Eligibility
  • Shift Allocation
  • Payroll Validation
  • Leave Approval
  • Performance Rating

Nested IF

=IF(A2>=90,"A",IF(A2>=75,"B",IF(A2>=50,"C","Fail")))

Nested IF allows you to test multiple conditions by placing one IF function inside another.
