AVERAGE Function

Calculate average values quickly using Excel AVERAGE functions with HR examples.

Function Overview

The AVERAGE function calculates the arithmetic mean of numbers. It is widely used in HR reports for salary analysis, attendance calculation, overtime analysis and employee performance reports.

Syntax

=AVERAGE(number1, [number2], ...)

Example:

=AVERAGE(C2:C10)

Arguments Explanation

Argument Description
number1 First number or cell range for calculating average
number2 Additional numbers or ranges (optional)
Range A group of cells containing numeric values

Basic Example

Employee salary data is available in column C. We need to calculate the average salary.

Employee Department Salary
Rahul Production 25000
Amit Quality 30000
Neha HR 28000
=AVERAGE(C2:C4)

Result: Average salary of all employees.

HR Practical Example 1: Average Salary

HR team can use the AVERAGE function to analyze average employee salary department-wise.

Employee Department Salary
101 Production 25000
102 Production 30000
103 Quality 35000

Average Production Salary:

=AVERAGEIF(B2:B4,"Production",C2:C4)

This formula calculates only Production department average salary.

HR Practical Example 2: Attendance Average

Calculate average attendance percentage of employees.

Employee Attendance %
Rahul 96
Amit 92
Neha 98
=AVERAGE(B2:B4)

Result gives average attendance percentage.

AVERAGEIF Function

AVERAGEIF calculates average based on one condition.

=AVERAGEIF(range,criteria,average_range)

Example: Average salary of Production employees.

=AVERAGEIF(B:B,"Production",C:C)

AVERAGEIFS Function

AVERAGEIFS calculates average using multiple conditions.

=AVERAGEIFS(C:C,B:B,"Production",D:D,"Active")

Example: Average salary of Active Production employees.
