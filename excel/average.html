Syntax

=AVERAGE(number1, [number2], ...)

Description

The AVERAGE function calculates the arithmetic mean of numbers. It is used to find the average value from a range of cells. In HR reports, it is commonly used for calculating:

  • Average Employee Salary
  • Average Attendance Percentage
  • Average Overtime Hours
  • Average Experience
  • Average Training Hours

Arguments

Argument Description
number1 First number or cell range to calculate average.
number2 Additional numbers or ranges (optional).

Example 1

=AVERAGE(C2:C10)

Calculates the average value from cells C2 to C10.

Example 2

=AVERAGE(B2:B31)

Calculate the average attendance percentage of employees.

HR Practical Example

HR can use the AVERAGE function to analyse employee salary data.

Employee Department Salary
Rahul Production 25000
Amit Quality 30000
Neha HR 28000
=AVERAGE(C2:C4)

Result: Average salary of all employees.

AVERAGEIF Function

AVERAGEIF calculates average values based on one condition.

=AVERAGEIF(range,criteria,average_range)

Example

Find average salary of Production department employees.

=AVERAGEIF(B:B,"Production",C:C)

AVERAGEIFS Function

AVERAGEIFS calculates average values using multiple conditions.

=AVERAGEIFS(C:C,B:B,"Production",D:D,"Active")

Example: Calculate average salary of active Production employees.
