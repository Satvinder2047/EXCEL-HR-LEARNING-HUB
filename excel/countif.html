COUNTIF Function

Count data based on specific conditions using Excel COUNTIF function with HR examples.

Function Overview

COUNTIF is used to count the number of cells that meet a specific condition. HR professionals use COUNTIF for employee headcount, department analysis, attendance tracking and compliance reports.

Syntax

=COUNTIF(range, criteria)

Example:

=COUNTIF(B2:B100,"Production")

Arguments Explanation

Argument Description
range The cells where Excel checks the condition
criteria The condition used for counting

Basic Example

Count employees working in Production department.

Employee Code Name Department
1001 Rahul Production
1002 Amit Quality
1003 Neha Production
=COUNTIF(C2:C4,"Production")

Result: 2 employees are working in Production.

HR Practical Example 1: Department Headcount

HR can use COUNTIF to calculate department-wise manpower.

Department Total Employees
Production 50
Quality 20
Engineering 15
=COUNTIF(B:B,"Production")

Counts all employees belonging to Production department.

HR Practical Example 2: Attendance Status

Count employees who are absent.

Employee Status
Rahul Present
Amit Absent
Neha Present
=COUNTIF(B2:B4,"Absent")

Result: Total absent employees.

COUNTIF with Numbers

Count employees having attendance above 90%.

=COUNTIF(C:C,">90")

Counts all employees where attendance percentage is more than 90.

COUNTIF with Wildcards

Wildcards help search partial text.

=COUNTIF(A:A,"Sat*")

Counts names starting with "Sat".


=COUNTIF(A:A,"*Kumar")

Counts names ending with "Kumar".
