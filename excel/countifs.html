COUNTIFS Function

Count data using multiple conditions with Excel COUNTIFS function and HR examples.

Function Overview

COUNTIFS is an advanced counting function used when we need to apply multiple conditions while counting data. HR teams use COUNTIFS for manpower reports, attendance analysis, recruitment tracking and compliance monitoring.

Syntax

=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2], ...)

Example:

=COUNTIFS(B:B,"Production",C:C,"Active")

Arguments Explanation

Argument Description
criteria_range1 The first range where Excel checks the condition
criteria1 The first condition to apply
criteria_range2 Additional range for second condition
criteria2 Additional condition (optional)

Basic Example

Count active employees working in Production department.

Employee Department Status
Rahul Production Active
Amit Quality Active
Neha Production Inactive
=COUNTIFS(B2:B4,"Production",C2:C4,"Active")

Result: Counts only active Production employees.

HR Practical Example 1: Active Manpower Report

HR can use COUNTIFS to prepare department-wise active manpower reports.

Department Employment Status Count
Production Active 120
Quality Active 35
Engineering Active 20
=COUNTIFS(A:A,"Production",B:B,"Active")

Counts active Production employees.

HR Practical Example 2: Attendance Analysis

Count employees having attendance below 90% and status Active.

Employee Attendance % Status
Rahul 88 Active
Amit 95 Active
Neha 85 Active
=COUNTIFS(B:B,"<90",C:C,"Active")

Counts active employees with attendance below 90%.

HR Practical Example 3: Recruitment Tracker

Count candidates based on department and interview status.

=COUNTIFS(B:B,"Production",C:C,"Selected")

Counts selected candidates for Production vacancies.

COUNTIFS with Dates

Count employees joined in a specific year.

=COUNTIFS(A:A,">=01-01-2026",A:A,"<=31-12-2026")

Useful for joining reports and recruitment MIS.
