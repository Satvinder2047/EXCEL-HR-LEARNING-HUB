Syntax

=SUM(number1,[number2],...)

Description

The SUM function adds numbers, cell references, or ranges together. It is one of the most commonly used Excel functions for performing calculations.

In HR, Finance, Payroll, and Administration, the SUM function is widely used to calculate totals such as salaries, overtime, attendance, leave balances, incentives, and expenses.

Arguments

Argument Description
number1 First number, cell reference, or range to add.
number2... Additional numbers or ranges (optional).

Example 1

=SUM(A2:A10)

Adds all numbers from cells A2 through A10.

Example 2

=SUM(B2,C2,D2)

Adds values from multiple cells.

Example 3

=SUM(A2:A10,C2:C10)

Adds multiple ranges in a single formula.
