Syntax

=SUM(number1,[number2],...)

Description

The SUM function adds numbers, cell references, or ranges together. It is one of the most frequently used Excel functions for calculations.

Arguments

Argument Description
number1 First number or range.
number2... Additional numbers or ranges (optional).

Example 1

=SUM(A2:A10)

Adds all numbers from cell A2 to A10.

Example 2

=SUM(B2,C2,D2)

Adds values from multiple cells.
